## 📂 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm before running the project locally.

### Installation

Clone the repository:

```bash
git clone https://github.com/Vinnie-kyalo/vinton-vision-craft.git
```

Navigate to the project directory:

```bash
cd vinton-vision-craft
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to preview the application.

### Production Build

Build the application for production:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
